Tech Stack & Domain Expertise

La nostra matrice tecnologica

Uno stack multi-vendor che copre l'intero perimetro dell'automazione industriale: dal PLC al cloud, dalla sicurezza di rete alla progettazione elettrica.

⚙️ PLC & Motion

  • Siemens Ecosystem: S7-1500/1200 (TIA Portal V18-V20+), STEP 7, Safety Integrated.
  • SCADA/HMI: WinCC Unified, WinCC Prof, SIMATIC AX.
  • Motion: Sinamics S120/G120, Simotion, S7-1500T (assi interpolati, camme).
  • Multi-vendor: CODESYS, Rockwell Studio 5000, Beckhoff TwinCAT, Gefran.

🌐 Convergenza IT/OT

  • Linguaggi: C#, Python, TypeScript, JavaScript, HTML5, SQL, C++.
  • Edge & container: Docker, Linux OS a bordo macchina, microservizi Edge AI.
  • IIoT & protocolli: OPC-UA (Native & Secure), Modbus TCP, REST API.
  • Web HMI: interfacce operatore di nuova generazione in React / Node.js.

🛡️ Cybersecurity & Norme

  • Normative UE: Cyber Resilience Act (CRA), Regolamento Macchine 2023/1230.
  • Security OT: IEC 62443 (Security by Design), hardening di rete.
  • Standard: ISA-88, OMAC / PackML, IEC 61131-3.
  • Bus di campo: Profinet (Engineer certificato), Profibus, EtherNet/IP, IO-Link.

📐 CAD & Dev Tools

  • CAD elettrico: EPLAN Electric P8, SPAC, AutoCAD 2D/3D, EXEL Integra.
  • DevOps: Git / GitLab, VS Code per automazione.
  • Virtual testing: simulazione preventiva della logica prima del cantiere.
